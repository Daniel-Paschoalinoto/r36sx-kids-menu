EN: Put YOUR pictures here, then write their names in config.toml:
      photo.jpg   -> picture on the start screen (a person, a pet...)
      mascot.png  -> picture on the menu screens (a game character, a logo...)
      font.ttf    -> optional font
    Nothing here is uploaded to GitHub. If a file is missing, a drawn placeholder is used.
